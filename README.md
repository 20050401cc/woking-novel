## 简介

WOOKING 书阁是一个纯前端原创小说在线阅读平台，支持多作品书架、章节阅读、主题切换，零依赖可直接部署。

## 作品列表

| 作品 | 类型 | 说明 |
|------|------|------|
| 灰烬协议 | 玄幻 | 灰烬之中，协议重启 |
| 万象清算 | 玄幻 | 重生后我让天命退位 |

## 功能

- 多作品书架展示
- 章节阅读 + 进度记忆
- 深色/浅色主题切换
- 响应式设计，移动端友好
- 纯静态，零后端依赖

## 运行

```bash
python -m http.server 8080
# 或直接打开 index.html
```

## 技术栈

- 原生 HTML/CSS/JavaScript
- CSS Custom Properties 主题系统
- 数据驱动渲染（JSON 到书架/章节）
